# Motivational Quotes App

A beautiful, interactive web application that provides random motivational quotes tailored to your current mood. Edit quotes to personalize them and make them your own!

## Features

✨ **Random Quote Generator** - Get inspiring quotes with a single click  
🎭 **Mood-Based Filtering** - Filter quotes by your current mood:
- 😊 Happy
- 💪 Motivated  
- 😔 Sad
- 😰 Anxious
- 😴 Tired

✏️ **Edit Quotes** - Customize any quote to make it more personal and meaningful to you  
📊 **Live Stats** - See how many quotes are available for your selected mood  
🎨 **Beautiful UI** - Modern, responsive design with smooth animations

## How to Use

1. Open `index.html` in your web browser
2. Select your current mood from the dropdown menu
3. Click "🎲 Get Random Quote" to display a motivational quote
4. Click "✏️ Edit Quote" to customize the quote text or author
5. Save your changes or cancel to keep the original

## Files

- `index.html` - Main HTML structure
- `styles.css` - Styling and animations
- `app.js` - JavaScript logic for quote management and mood filtering

## Technology Stack

- Pure HTML5
- CSS3 with modern gradients and animations
- Vanilla JavaScript (no frameworks required)

## Installation

No installation required! Simply:
1. Clone this repository
2. Open `index.html` in any modern web browser
3. Start getting motivated!
